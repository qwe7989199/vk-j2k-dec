The smoke shader reads the flattened codeblock records and the packed compressed
byte stream on GPU, then validates per-codeblock byte ranges and checksums
against the CPU plan. The MQ smoke runs the JPEG 2000 MQ state machine on the
GPU against real codeblock bytes and compares the decoded bits plus registers
against the CPU `MqDecoder`. The full Tier-1 smoke runs every MQ-coded pass for
every codeblock on GPU, including cleanup, significance propagation, magnitude
refinement, run-length mode, significance contexts, sign contexts, and
coefficient/significance state updates. It writes a flat GPU coefficient buffer
and compares all 3,177,152 coefficients against CPU Tier-1. The shader now keeps
state in workgroup memory, caches neighbor counts, uses visit-generation bits
instead of clearing visit flags every significance pass, and avoids cleanup-only
visit writes that cannot be read again in the same bitplane. The benchmark mode
creates the decode flow once, dispatches the same frame repeatedly, and reads
back once for correctness.

The scatter smoke is the next GPU handoff step: it uses precomputed codeblock
rectangles to scatter the flat Tier-1 coefficient buffer into concatenated
component/subband plane storage. That validates the layout needed to feed GPU
Tier-1 output directly into GPU DWT without a CPU coefficient placement pass.
The cleanup+scatter bench keeps that flat buffer device-local and records the
cleanup and scatter shaders into the same command buffer loop; scatter adds
effectively no hot-path cost beside MQ decode on the local frame.
